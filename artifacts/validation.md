## Assumptions and honest boundaries

- All gameplay is for points; no wagers or token spending were introduced. Wallet connection is optional until stamping a score.
- The public APIs are the only source of live hamster/economy/settlement/account state. Practice is selected explicitly and visibly labeled. No simulation silently replaces live data.
- Distance fields are treated as meters, as named by `distance_m` / `distance_meters`; generic `distance` is accepted as an alias. Successful production API schema and units could not be confirmed during the service challenge.
- A wheel score stores the Squeekchain height at join, a predictor stores its resolving settlement height, and rhythm stores its historical seed block. No Ethereum block height is substituted.
- Scores and charge are local. A static export has no supplied shared ranking/charge service. The interface discloses this rather than implying cross-visitor synchronization.
- The on-chain action attests to submitted calldata; client-side score integrity is not independently proven. Pending proof links persist, including across reload, but checking a late confirmation after timeout/reload uses Etherscan.

## Findings and corrections

Source references point to the final source location containing the correction, not a generated bundle. Earlier screenshots/probe output were temporary review scaffolding; retained evidence reflects the final export.

1. **High · Layout: the escape action fell below the first phone screen.** `src/styles.css:1835`, `src/styles.css:1880` (`.run-control` grid). Initially the desktop multiplier/stat stack followed a tall habitat and a wrapped source-navigation row. Changed to the compact two-column multiplier/stats arrangement and moved the phone source switch into the habitat heading. At 390 × 844, the full action now spans y≈753.84–799.84. Rechecked by browser assertion and `screenshots/mobile-390.png`.
2. **Medium · Typography: multiplier inline baseline overlapped its caption.** `src/styles.css:1821` (`.multiplier > .mono { display: block; }`). The first probe reported one text overlap at 390. Changed the value to a block and kept spacing within the scale. Final layout check reports zero overlaps at 320/390/1440; screenshot confirms separation.
3. **Medium · Writing: repeated two-beat slogans competed with the game.** `src/App.tsx:268`, `src/App.tsx:315`. Replaced the intro with “A live arcade powered by Squeekchain.” and the idle multiplier line with “Ready when you are.”, and simplified supporting state copy. The first probe counted six two-beat lines; final probe reports none and 35 prose words on the first phone screen.
4. **High · Accessibility: the compact stream utility lost its accessible name when visible text hid.** `src/App.tsx:295` (`aria-label={stream ? ...}`). Added a stable explicit label matching the action. Phone Stream view/Exit stream view navigation and the automated accessibility audit now pass.
5. **High · Wallet functionality: Coinbase’s optional SDK peer was not initially installed.** `package.json:16` (`@coinbase/wallet-sdk`). Dependency inspection found the connector without its optional peer, which would prevent that path from initializing. Added the SDK explicitly; final export includes its lazy runtime chunk. Phone picker/mark/connector presence tested. Real passkey creation remains unverified.
6. **Medium · Wallet links: Rabby’s initial URL omitted its command.** `src/lib/wallet.ts:31`. Verified the vendor’s production handler, then changed to `/mobile/?_cmd=open-dapp&dapp=<encoded current URL>`. The phone sheet validation checks the exact command, path, retained page URL, all four marks, and Coinbase Smart Wallet. Physical handoff remains unverified.
7. **High · Layout/accessibility: 200% text enlargement overflowed the phone viewport.** `src/styles.css:1954` (reflow rules). Measured 598px scroll width in a 390px viewport, originating in header, tabs and data/control rows. Allowed wrapping and zero-minimum grid tracks while preserving the enlarged font size. Recheck reports 390px scroll width, no elements beyond the viewport, and readable reflow in the full enlarged-text screenshot. Normal first-screen geometry remained unchanged.

Packaging correction: moved local WOFF2 source assets into `src/assets/fonts/`, so Vite emits one runtime copy of each font. Preserved required fonts, wallet assets, share image, and licenses; removed no required runtime feature. No dependency archives or vendored registries were added.

## Completion and limits

The repository bundle includes source, lockfile, production runtime assets, DESIGN.md, README, and these records. The final path and byte check is recorded in `bundle-audit.json`. That audit uses the candidate Git submission files, excludes generated/cache directories at every nesting level, rejects submodules and dependency archives, and enforces the assignment’s 8,388,608-byte cap.
